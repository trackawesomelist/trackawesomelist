### Interfacing Software

*   [CCU-AI-MCP (⭐3)](https://github.com/mdzio/ccu-ai-mcp) - MCP-Server für OpenCCU/CCU, gibt KI-Assistenten (LLMs) über konfigurierbare HM-Skripte Zugriff auf das Smart Home.
