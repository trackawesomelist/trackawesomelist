## :hammer\_and\_wrench:   Libraries and SDKs

### Ballerina

*   [ballerina-slack-library (⭐108)](https://github.com/ballerina-platform/module-ballerinax-slack) - Ballerina library for Slack.

### C\#

*   [margiebot (⭐123)](https://github.com/jammerware/margiebot) - A .NET library designed to make building bots for Slack fast, easy, and fun
*   [Slack.Webhooks (⭐172)](https://github.com/nerdfury/Slack.Webhooks) - A library to work with Slack webhooks more easily
*   [SlackAPI (⭐456)](https://github.com/Inumedia/SlackAPI) - A third-party implementation of Slack's API written in C#

### Erlang

*   [slacker (⭐57)](https://github.com/julienXX/slacker) - Erlang Slack REST API wrapper

### Go

*   [webhook (⭐12k)](https://github.com/adnanh/webhook) - Easily run commands in response to HTTP webhook requests from Slack

### Java

*   [java-slack-sdk (⭐603)](https://github.com/slackapi/java-slack-sdk) - Slack's official Java framework for building Slack apps
*   [simple-slack-api (⭐474)](https://github.com/Ullink/simple-slack-api) - A Slack client library in Java

### JavaScript/TypeScript

*   [appstore-webhook-proxy (⭐27)](https://github.com/yannisalexiou/appstore-webhook-proxy) - App Store Webhook Proxy for Microsoft Teams & Slack.
*   [bolt-js (⭐2.9k)](https://github.com/slackapi/bolt-js) - Slack's official JavaScript framework for building Slack apps
*   [jsx-slack (⭐507)](https://github.com/yhatt/jsx-slack) - Build JSON object for Slack Block Kit surfaces from JSX
*   [node-slack-sdk (⭐3.4k)](https://github.com/slackapi/node-slack-sdk) - Slack's official SDK for Node.js
*   [slack-block-builder (⭐637)](https://github.com/raycharius/slack-block-builder) - Lightweight Node.js library for building Slack Block Kit UIs, with a declarative syntax inspired by SwiftUI

### PHP

*   [SlackBundle (⭐39)](https://github.com/DZunke/SlackBundle) - SlackBundle for Symfony2
*   [slack-php-app-framework (⭐49)](https://github.com/slack-php/slack-php-app-framework) - Robust PHP framework for building Slack apps in PHP
*   [slack-php-block-kit (⭐29)](https://github.com/jeremeamia/slack-block-kit) - Fluent interface for composing Slack Block Kit messages and modals in PHP
*   [slack-php-socket-mode (⭐10)](https://github.com/slack-php/slack-php-socket-mode) - A Socket Mode implementation for [slack-php-app-framework (⭐49)](https://github.com/slack-php/slack-php-app-framework)
*   [slack-php-slick (⭐7)](https://github.com/slack-php/slack-php-slick) - Dependency-free micro-framework for building Slack apps in PHP

### PowerShell

*   [PSSlack (⭐272)](https://github.com/RamblingCookieMonster/PSSlack) -  PowerShell module for simple Slack integration.

### Python

*   [blockkit (⭐104)](https://github.com/imryche/blockkit) - A fast way to build Block Kit interfaces in Python
*   [bolt-python (⭐1.3k)](https://github.com/slackapi/bolt-python) - Slack's official Python framework for building Slack apps
*   [django-slack (⭐245)](https://github.com/lamby/django-slack) - Slack integration for Django, using the templating engine to generate messages
*   [django-slack-oauth (⭐54)](https://github.com/izdi/django-slack-oauth) - Slack OAuth module for Django
*   [python-slack-events-api (⭐340)](https://github.com/slackapi/python-slack-events-api) - Slack Events API adapter for Python
*   [python-slack-sdk (⭐4k)](https://github.com/slackapi/python-slack-sdk) - Slack's official SDK for Python
*   [slackblocks (⭐75)](https://github.com/nicklambourne/slackblocks) - Python API for building Slack Block Kit messages
*   [slack-php-api (⭐255)](https://github.com/jolicode/slack-php-api) - PHP Slack client based on the official OpenAPI specification
*   [slacker-cli (⭐187)](https://github.com/juanpabloaj/slacker-cli) - Messages to slack from the command line
*   [slashbot (⭐17)](https://github.com/ebrassell/slashbot) - An easy way to create slash commands using AWS Lambda functions
*   [boltworks (⭐2)](https://github.com/YSaxon/boltworks) - Extensions to Slack's bolt framework: expandable GUIs, easier callbacks, richer CLIs

### R

*   [slackr (⭐308)](https://github.com/hrbrmstr/slackr) - A package to send webhook API messages to Slack channels/users from R

### Ruby

*   [slack-notifier (⭐1.5k)](https://github.com/stevenosloan/slack-notifier) - A simple wrapper for posting to Slack
*   [slack-notify (⭐93)](https://github.com/sosedoff/slack-notify) - Send notifications to Slack
*   [slack-poster (⭐51)](https://github.com/rikas/slack-poster) - Simple gem to post messages on Slack using webhooks
*   [slack-ruby-block-kit (⭐74)](https://github.com/CGA1123/slack-ruby-block-kit) - A ruby wrapper for Slack's Block Kit
*   [slack-ruby-bot (⭐49)](https://github.com/dblock/slack-ruby-bot) - The easiest way to write a Slack bot in Ruby
*   [slack-ruby-bot-server (⭐268)](https://github.com/slack-ruby/slack-ruby-bot-server) - Ruby library for building Slack applications
*   [slack-ruby-client (⭐17)](https://github.com/dblock/slack-ruby-client) - A Ruby client for the Slack Web and RealTime Messaging APIs

### Rust

*   [slack-morphism-rust (⭐227)](https://github.com/abdolence/slack-morphism-rust) - A modern async Slack API client for Rust

### Scala

*   [slack-scala-client (⭐191)](https://github.com/gilbertw1/slack-scala-client) - A Scala Slack client for the Web and RTM API

### Swift

*   [SwiftBlocksUI (⭐72)](https://github.com/SwiftBlocksUI/SwiftBlocksUI/) - Interactive Slack messages and modals using a SwiftUI-like declarative style

### CoffeeScript

*   [jinora (⭐87)](https://github.com/sdslabs/jinora) - Slack webhook app to create anonymous public channels
