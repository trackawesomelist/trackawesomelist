## [Nov 23 - Nov 29, 2026](/content/2026/47/README.md)

### Server Software / General Purpose

*   [FreeSWITCH (⭐5.3k)](https://github.com/signalwire/freeswitch) - Open source communications server for voice, video, messaging and conferencing.
*   [Asterisk](https://www.asterisk.org/) - PBX framework supporting multiple protocols and platforms.

### Server Software / SIP Servers

*   [Kamailio](https://www.kamailio.org/w/) - Open source SIP server for routing, registration, presence and large-scale deployments.
*   [OpenSIPS](https://opensips.org/) - Open source SIP proxy and application server for VoIP platforms.
*   [FreeSBC (⭐373)](https://github.com/rasonyang/freesbc) - Open source SIP/WebRTC edge proxy with an embedded RTP relay for FreeSWITCH and Asterisk.
*   [P-KISS-SBC (⭐114)](https://github.com/mwolff44/pk-sbc) - Kamailio and rtpengine-based session border controller for connecting SIP trunks and PBXs.

### Server Software / Media Servers

*   [LiveKit (⭐22k)](https://github.com/livekit/livekit) - Open source WebRTC server and SDK ecosystem for real-time audio, video and data.
*   [rtpengine (⭐1k)](https://github.com/sipwise/rtpengine) - RTP and UDP based media traffic proxy, usable as a kernel module.
*   [MediaMTX (⭐21k)](https://github.com/bluenviron/mediamtx) - Media server and proxy bridging WebRTC, RTSP, RTMP and SRT streams, with recording and playback.
*   [go2rtc (⭐15k)](https://github.com/AlexxIT/go2rtc) - Camera streaming gateway with WebRTC viewing, RTSP restreaming and two-way audio integrations.

### Server Software / STUN/TURN

*   [STUNner (⭐1.1k)](https://github.com/l7mp/stunner) - Kubernetes-native STUN/TURN gateway for WebRTC media.

### Clients / STUN/TURN

*   [Web SIP Phone (⭐8)](https://github.com/rasonyang/web-sip-phone) - Chrome extension maintaining SIP/WebRTC audio for server-controlled call center agents.
*   [baresip (⭐2.3k)](https://github.com/baresip/baresip) - Modular SIP user agent with command-line controls, audio/video calls and pluggable media modules.

### Operations / Monitoring

*   [sip-exporter (⭐58)](https://github.com/aibudaevv/sip-exporter) - Open-source eBPF sensor exporting Prometheus metrics and Grafana dashboards for host-observed IPv4/UDP SIP and correlated RTP/RTCP.
*   [rtcStats (⭐47)](https://github.com/rtcstats/rtcstats) - WebRTC API trace and getStats collection, storage and feature extraction tooling.
*   [SIP3 Community Edition](https://sip3.io/docs/InstallationGuide.html) - Open source SIP/RTP capture, analysis and monitoring components with community deployment tooling.

### Operations / Testing

*   [SIPp (⭐1.2k)](https://github.com/SIPp/sipp) - Traffic generator and scenario-based test tool for the SIP protocol.

### Operations / Web/API Interfaces

*   [Kazoo (⭐992)](https://github.com/2600hz/kazoo/tree/4.3) - Legacy open source VoIP API platform built on FreeSWITCH and Kamailio, available in the public 4.3 branch.
*   [AI Native Call Center (⭐666)](https://github.com/rasonyang/ai-native-callcenter) - FreeSWITCH-based call center with speech-to-speech AI, agent queues and a web interface/API.

### Operations / Billing

*   [CGRateS (⭐528)](https://github.com/cgrates/cgrates) - Open source rating, charging and billing engine for telecom and ISP services.

### Developer Resources / Tutorials

### Developer Resources / JavaScript Libraries
