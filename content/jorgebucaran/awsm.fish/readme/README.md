# awsm.fish [![Awesome](https://awesome.re/badge.svg)](https://awesome.re)

> Fish is the sassy & user-friendly command line shell you never knew you needed for Linux, macOS, and the whole gang. Out with the old-fashioned shells that skimp on features for the sake of every last byte of RAM—finally, a command line shell for the 90s!

Welcome to the ultimate treasure trove of handpicked plugins, prompts, and other [Fish](https://fishshell.com/) goodies. You see, this isn't just any collection—we curate only the best of the best Fish projects for your friendly interactive shell. Got a top-notch project you want featured here? [Send us a pull request (⭐5.1k)](https://github.com/jorgebucaran/awesome-fish/fork), join the crew!

## Plugins

*   [z (⭐1.5k)](https://github.com/jethrokuan/z) - Pure-Fish [`rupa/z`](https://github.com/rupa/z)-like directory jumping
*   [fzf (⭐2.7k)](https://github.com/PatrickF1/fzf.fish) - Ef-🐟-ient key bindings for [`junegunn/fzf`](https://github.com/junegunn/fzf). ([Alternative (⭐910)](https://github.com/jethrokuan/fzf))
*   [nvm (⭐2.7k)](https://github.com/jorgebucaran/nvm.fish) - Node.js version manager lovingly made for Fish
*   [Done (⭐968)](https://github.com/franciscolourenco/done) - Automatically receive notifications after a long process finishes
*   [Replay (⭐485)](https://github.com/jorgebucaran/replay.fish) - Run Bash commands replaying changes in Fish. ([Alternative (⭐2.5k)](https://github.com/edc/bass))
*   [Spark (⭐381)](https://github.com/jorgebucaran/spark.fish) - Sparklines for Fish
*   [Fisher (⭐9.5k)](https://github.com/jorgebucaran/fisher) - Manage functions, completions, bindings, and snippets from the CLI
*   [Fundle (⭐387)](https://github.com/danhper/fundle) - `config.fish`-based plugin manager
*   [GitNow (⭐490)](https://github.com/joseluisq/gitnow) - A collection of utility functions to speed up your git workflow
*   [Sponge (⭐459)](https://github.com/meaningful-ooo/sponge) - Clean command history from typos automatically
*   [Autopair (⭐586)](https://github.com/jorgebucaran/autopair.fish) - Auto-complete matching pairs in the Fish command-line. ([Alternative (⭐301)](https://github.com/laughedelic/pisces))
*   [Getopts (⭐236)](https://github.com/jorgebucaran/getopts.fish) - CLI options parser (alternative to the [`argparse`](https://fishshell.com/docs/current/cmds/argparse.html) builtin)
*   [Fishtape (⭐386)](https://github.com/jorgebucaran/fishtape) - TAP-based test runner for Fish
*   [Pufferfish (⭐435)](https://github.com/nickeb96/puffer-fish) - Text Expansions for Fish
*   [Projectdo (⭐94)](https://github.com/paldepind/projectdo) - Context-aware single-letter abbreviations to build, run, and test any project
*   [Magic Enter (⭐38)](https://github.com/mattmc3/magic-enter.fish) - Run a default command when no command was given
*   [Virtualfish (⭐1.1k)](https://github.com/adambrenecki/virtualfish) - Virtualenv wrapper
*   [Async Prompt (⭐555)](https://github.com/acomagu/fish-async-prompt) - Make your prompt asynchronous
*   [Apple Touchbar (⭐96)](https://github.com/rodrigobdz/fish-apple-touchbar) - Customize your [Touch Bar](https://developer.apple.com/design/human-interface-guidelines/macos/touch-bar/touch-bar-overview) in iTerm2
*   [Abbreviation Tips (⭐385)](https://github.com/Gazorby/fish-abbreviation-tips) - Remembering abbreviations by displaying tips when you can use them
*   [Base16 Fish (⭐33)](https://github.com/FabioAntunes/base16-fish-shell) - A pure Fish solution to change your shell's default ANSI colors
*   [Web Search (⭐23)](https://github.com/Veirt/web-search.fish) - A plugin to search the web from Fish. Inspired by [`oh-my-zsh/web-search`](https://github.com/ohmyzsh/ohmyzsh/tree/master/plugins/web-search)
